# 재무 분석 계약과 후속 구현

**현재 상태: Phase 2의 계약만 정의. 매출·비용·손익분기·회수기간 계산은 Phase 7이다.**

FinancialEngine은 SimulationResult와 명시적인 FinancialAssumption을 받는다. 시뮬레이션 이벤트 엔진과 분리하며, 계산 결과는 사용한 실행 ID, 비용 가정, 통화, 기간, 알고리즘 버전을 추적해야 한다.

후속 입력 범위는 객단가, 원재료비율, 임대료, 인건비, 공과금, 로열티, 배달 수수료, 마케팅, 기타 고정비, CAPEX, 가맹비, 인테리어비다. 일별 영업 결과를 월간으로 환산할 때 영업일 수와 평일/주말 구성, 비용 중복 여부를 명시한다.

후속 출력 범위는 월 매출, COGS, 인건비/고정비/변동비, 영업이익/이익률, 손익분기 매출/고객 수, 추정 투자 회수기간이다. 분모가 0이거나 손익분기/회수기간을 정의할 수 없으면 null과 이유를 반환해야 한다. 음수 이익에서 음수 회수개월을 정상 결과처럼 표시하지 않는다.

모든 수치는 관측 데이터와 사용자가 설정한 조건에 따른 시나리오 결과다. 미래 매출 보장이나 자동 GO/NO-GO 판단으로 표현하지 않는다. 실제 재무 계산 구현 시 회계·세금·자금조달 포함 범위를 별도로 정하고 테스트한다.
