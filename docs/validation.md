# 검증 기록

2026-09-23, Windows / Node.js 22.23.2 / Chrome headless WebGL로 실행했습니다.

최종 결과: **프로덕션 빌드 성공, 단위·형상 테스트 37개 통과, 브라우저 시나리오 6개 통과.** 최종 정규화 JSON은 벽19개·문6개·공간7개·가구/설비125개로 총157개 요소입니다. 재현 스크립트의 JSON이 최종 `floorplan.json`과 완전히 일치합니다.

## 실제 브라우저

- 기준 PDF 원본과 PNG 오버레이가 정상 로드됨.
- 8,800 × 21,200 mm 기준과 테이블20개·의자72개가 JSON에 유지됨.
- SVG 벽 좌표, 사선 외곽과 원본의 정합성을 화면으로 확인함.
- 너비 변경, 회전, 드래그, 실행 취소, 추가·삭제가 저장 JSON에 반영됨.
- 검토 확인 전 GLB는 비활성화, 확인 후 Three.js 캔버스와 다운로드가 동작함.
- 6개 카메라 전환과 화면 캡처를 수행함.
- GLB 헤더·버전·길이, GLTF의 내장 buffer와 엔티티 식별자를 검사함.
- GLB를 GLTFLoader로 다시 읽었을 때 생성 전/후 모델 경계가 일치함.
- ZIP의 6개 PNG 이름·형식·1600×1200 해상도를 검사하고 개별 PNG도 다운로드함.
- 같은 PDF 업로드 시 PDF.js 렌더와 해당 SHA256의 JSON이 로드됨.
- 다른 실제 파일 `260712_백초밥-1.pdf`는 별도 보정으로 저신뢰 벽 후보를 생성하며 기준 식당 가구를 재사용하지 않음.
- 잘못된 JSON은 기존 도면을 유지하며 거부함. 수정 JSON은 속성값과 일치함.
- 전체 흐름의 pageerror 및 console.error가 없음을 검사함.
- 높이 일괄 적용·재질·조명·바닥 외곽 수정이 저장 JSON에 반영되고 기존 검토 승인이 해제됨.

## 수학과 형상

- 중첩 PDF 변환행렬·Form·clipping·색상 typed-array와 평행선 후보, 축척 보정.
- 개구부 중복 구간, 사선·수직 벽, 수직 교차 벽의 잘못된 자동 개구부 제외.
- 가구가 지정된 footprint·높이를 벗어나지 않음.
- 6개 카메라 × 3개 화면비에서 전체 경계가 viewport 안에 들어옴.
- Top 방향, mm→m 변환, JSON 검증, 회전 polygon 수정.

## 증거와 한계

`tmp/e2e/`에 UI 화면·JSON·GLB·GLTF·6개 PNG·ZIP이 있습니다. 테스트 코드는 `tests/workflow.spec.ts`, `src/*.test.ts`입니다.

최종 기준 출력은 `output/sample/`에 보관했습니다. GLB는1,391,688바이트이며 GLTFLoader로 재로드한 모델 경계 오차는 **0 m**입니다. `output/sample/verification.json`에 수치가 있습니다. 원본과 도형의 중첩 검증은 [비교 이미지](figures/source-overlay.png)로 확인할 수 있습니다.

범용 의미 인식 정확도를 보장하는 검사는 아닙니다. 일반 PDF 후보에는 잘못된 선과 누락이 있을 수 있습니다. 높이·입면·재료·조명은 원본에 없는 가정입니다. 낮은 신뢰도 요소와 원본/표기 치수 불일치는 사람이 확인해야 합니다. 시공도·BIM·법규·설비 간섭 검증은 범위에 포함하지 않습니다.
